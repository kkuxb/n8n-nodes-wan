# Wan 视频生成

在 n8n 工作流中使用 Wan 3.0 生成视频，支持文字生成、图片生成、多素材参考，以及对已有视频进行编辑和延长。可选择**龙猫API**或**麦包API**作为服务商。

填写提示词并执行节点，即可等待生成完成并获取视频文件。默认使用 **1080P、5 秒、自适应比例、有声视频**，自动等待并下载结果。

## 安装节点

1. 打开 n8n 的 **设置（Settings）→ 社区节点（Community nodes）**。
2. 点击 **安装（Install）**。
3. 在包名称中输入 `n8n-nodes-wan`，确认社区节点提示后点击安装。
4. 安装完成后，在工作流中搜索并添加 **Wan 视频生成**。

## 配置服务商

使用前，准备所选服务商的 API Key，并确保账号有可用的视频生成额度。

在节点中创建 **Wan API** 凭证：

凭证页只需选择服务商并填写 API Key；该凭证供「Wan 视频生成」节点使用。

| 设置 | 如何填写 |
| --- | --- |
| 服务商 | 默认选择「龙猫API」，也可选择「麦包API」 |
| API Key | 填写所选服务商提供的 Key，然后保存凭证 |

服务商入口：[龙猫API](https://ai.lmao.net.cn) · [麦包API](https://ai.maibao.chat)。选好服务商后无需手动填写 API 地址。切换服务商时，请同时换成对应的 Key。

## 生成第一个视频

1. 添加 **Wan 视频生成** 节点并选择已保存的凭证。
2. 将操作设为 **创建任务**，创建模式选 **文生视频**。
3. 填写提示词，例如：

   > 一个橙色玩具机器人站在木桌上，缓慢向镜头挥手。窗外柔和的日光照入，固定机位，画面温暖自然，伴随轻柔的机械声。

4. 保持 **等待任务完成** 和 **下载视频** 开启，执行节点。
5. 生成完成后，在节点输出的 **Binary** 中查看或下载 `video` 文件。也可以将它传给后续的文件保存、云盘上传等节点。

输出同时提供 `videoUrl` 视频链接。自动下载会将视频交给工作流；若需长期保存，请连接后续保存或上传节点。

## 选择生成方式

模型固定为 **Wan 3.0 Video**，无需选择。操作可选「创建任务」或「查询任务」。

| 创建模式 | 适合做什么 | 需要准备什么 |
| --- | --- | --- |
| 文生视频 | 根据文字描述生成画面 | 提示词 |
| 首帧图生视频 | 让一张图片动起来 | 首帧图片，可补充动作与镜头提示词 |
| 首尾帧图生视频 | 生成从一张图片过渡到另一张图片的视频 | 首帧和尾帧图片，可补充过渡描述 |
| 多模态参考生视频 | 结合图片、视频、音频创作，或编辑、延长已有视频 | 参考素材，建议配合提示词 |

### 使用图片

图片来源可选择：

- **URL**：填写无需登录即可访问的图片链接。
- **Binary 文件**：使用上游节点传入的图片，填写对应的 Binary 属性名，例如 `data` 或 `image1`。可在上游节点输出的 Binary 页签中查看名称。

首帧和尾帧分别填写。多模态模式下，在 **参考素材** 中逐项添加图片、视频或音频；视频和音频使用可直接访问的链接。

添加素材时先选 **素材类型**。选择图片后，再选 **图片来源**：URL 显示「图片 URL」，Binary 文件显示「Binary 属性名」。选择视频或音频时，只需填写「素材 URL」。

### 使用多种参考素材

提示词中可以用「图1」「视频1」「音频1」指代素材，各类素材分别按添加顺序编号。例如添加了图片、视频、图片，它们分别对应图1、视频1、图2。

示例提示词：

> 保持图1中产品的外观，参考视频1的缓慢环绕镜头，在图2的场景中展示产品，使用音频1作为声音参考。

| 素材 | 准备要求 |
| --- | --- |
| 图片 | JPEG/JPG、PNG、BMP、WEBP；单张不超过 20 MB；每边 240–8000 像素；长宽比例不超过 8:1；不含透明内容 |
| 参考图片 | 最多 10 张 |
| 参考视频 | 最多 5 段，MP4/MOV；单段 1–15 秒，总计不超过 15 秒；单个文件不超过 100 MB |
| 参考音频 | 最多 5 段，WAV/MP3；单段 1–15 秒，总计不超过 15 秒；单个文件不超过 15 MB |
| 多模态参考总量 | 图片、视频、音频合计最多 20 项 |

素材链接应指向文件本身，而非需要登录的网页或分享预览页。最终是否接受素材，以服务商返回结果为准。

## 编辑或延长已有视频

将创建模式设为 **多模态参考生视频**，添加参考视频，再选择 **任务意图**。

编辑或延长时，新添加的素材默认选择 **视频**。你仍可切换为图片或音频，作为外观、场景或声音的补充参考；至少保留一段需要编辑或延长的视频。

### 视频编辑

1. 选择 **视频编辑**。
2. 在提示词中描述希望修改的内容，例如「把背景改为傍晚的海边，保留人物外观和动作」。
3. **输出视频总时长（秒）** 建议保留 `-1`，让模型自动决定。

### 视频延长

1. 选择 **视频延长**。
2. 选择向后、向前或双向延长，并保持宽高比为 **自适应**。
3. 在提示词中描述新增的内容；双向延长时分别说明开头和结尾的内容。
4. 填写 **输出视频总时长（秒）**，或用 `-1` 自动决定。例如原视频 5 秒，希望再延长 3 秒，应填写 **8**。

只有一段参考视频时，**目标视频编号** 保持 `0` 即可；有多段视频时，填写要编辑或延长的视频编号，如 `1` 表示视频1。编辑和延长都需要填写提示词，实际效果由模型生成，不能保证原画面逐帧不变。

## 常用设置

| 设置 | 默认值 | 使用建议 |
| --- | --- | --- |
| 分辨率 | 1080P | 也可选 720P 或 480P |
| 宽高比 | 自适应 | 可选 16:9 横屏、9:16 竖屏等；视频延长保持自适应 |
| 视频时长 | 5 秒 | 可填 2–30 的整数秒数，或 -1 自动决定；编辑和延长默认自动 |
| 生成音频 | 开启 | 只需要无声画面时关闭 |
| 等待任务完成 | 开启 | 开启后，节点等待生成结果；关闭后先返回任务 ID |
| 最长等待时间 | 20 分钟 | 可根据生成耗时调整 |
| 下载视频 | 开启 | 成功后输出可供后续节点使用的视频文件；关闭后只获取结果信息和链接 |

有参考视频时，输入与输出视频时长合计不超过 30 秒。

**高级选项** 中可调整提示词改写、水印和随机种子。默认开启提示词改写、关闭水印；随机种子 `-1` 表示随机，固定种子也不保证每次画面完全一致。

## 查询已提交的任务

关闭「等待任务完成」后，节点会先返回 `taskId`。要获取结果，添加另一个 **Wan 视频生成** 节点：

1. 选择创建该任务时使用的服务商凭证。
2. 将操作设为 **查询任务**。
3. 填入任务 ID；从上游接收时可使用表达式 `{{ $json.taskId }}`。
4. 开启 **等待任务完成** 和 **下载视频**，执行节点。

如果只想查看当前进度，关闭等待即可。任务已经完成时，只要下载开关开启，单次查询也会获取视频文件。

## 获取和使用结果

| 输出内容 | 用途 |
| --- | --- |
| Binary 中的 `video` | 生成的视频文件；后续节点要求填写输入文件字段时，填写 `video` |
| `videoUrl` | 视频链接，建议及时保存视频 |
| `taskId` | 后续查询任务时使用 |
| `isSuccess` | 判断是否生成成功，可用于 IF 节点分支 |
| `status` | 查看当前状态，如排队、生成中、成功或失败 |

## 常见问题

**等待超时了，需要重新生成吗？**

先用任务 ID 查询原任务。等待超时不代表生成失败，重新执行「创建任务」会提交新的付费任务。

**生成成功了，但没有视频文件怎么办？**

先检查「下载视频」是否开启。如果输出有 `downloadError`，可以通过「查询任务」重新获取视频，无需重新生成。

**关闭等待后，节点还会自动下载吗？**

关闭等待后，创建操作只提交任务。请再使用「查询任务」获取结果，并保持下载开关开启。

**凭证测试通过，为什么仍然无法生成？**

请检查所选服务商的余额、视频模型权限、提示词和素材要求。凭证测试通过不代表账号一定有足够的生成额度。

**执行创建时出现超时或连接错误怎么办？**

先在服务商处核实是否已受理任务，避免重复收费。不建议对「创建任务」开启 n8n 的 Retry On Fail；查询或下载失败时，也应优先查询原任务。
