# Maibao Wan 3.0 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.
>
> 环境说明：上述为 writing-plans 模板的执行入口；编写本计划时这两个 skill 未列于当前可用技能中，不得假称已加载。执行时若仍不可用，在当前会话按以下任务顺序实施并逐项验证。本计划不自行启动代理或实现代码。

**Goal:** 交付独立的 n8n 麦包 Wan 3.0 视频节点，默认 1080P，支持创建后等待下载和独立查询恢复。

**Architecture:** 从现有 Seedance 项目选择性复用 n8n 接入模式和下载代码。为麦包单独实现凭证、请求、媒体校验、提示词编排、状态解析及有限轮询；纯函数和注入的 HTTP／时钟用于自动化验证。

**Tech Stack:** TypeScript、n8n-workflow、@n8n/node-cli、Node.js node:test；参考项目开发运行时 Node.js `>=24.15.0 <25`、npm 11；发布包的实际运行要求需通过依赖及目标 n8n 环境验证。

## Global Constraints

- 工作根目录：`D:/Projects/n8n-nodes-wan`；后续文件路径相对该根目录。
- 批准设计：`docs/plans/2026-10-13-wan3-maibao-design.md`。
- 包名 `n8n-nodes-wan`，节点名 `Wan 视频生成`，模型 `wan3.0-video`，服务商麦包。
- 默认值：1080P、adaptive、普通生成 5 秒、audio=true、prompt_extend=true、watermark=false、seed 省略。
- 创建默认等待完成；创建和查询均默认允许下载；20 秒查询间隔，默认最多 20 分钟。
- 图片 URL＋binary；视频／音频 URL；图片 Base64 经麦包验证通过才算完成。
- 四种创建模式，多模态下支持参考生成、编辑、延长；延长填写输出视频总时长。
- 不改动 Seedance 项目，不继承火山凭证、asset://、Seedream、列表／删除／取消功能。
- 创建 POST 不自动重试；查询和下载故障不得重新创建任务。
- 任务生成失败、查询失败、等待超时、下载失败分别表示。
- 不将 API Key、Windows 凭据读取逻辑、开发运行时或完整 Base64 打入包或夹具。
- 本计划不是 npm 发布指令；发布前另行执行发布流程。

## 证据准备与发布门槛

既有报告位置见设计文档第 2 节。当前仅验证 480P 文生视频、720P 图片 URL＋音频 URL；1080P 和新模式不可写成已经实测。

实施开始先核对官方 API 的 MIME、大小、seed 范围、素材组合和时长规则，以及麦包上传／Base64 支持。互联网资料读取按当前 agent-reach 技能进行；来源、获取日期、适用模型写入 `docs/verification/protocol.md`。不得把无法读取的资料补写成确定规则。

如果麦包拒绝图片 Base64，保留原始错误证据，此项属于已确认产品需求受阻，需反馈并调整设计；不得在 README 中假称 binary 可用，也不得自行接入新存储服务。

## 任务 4：可恢复的有限轮询

**Files:** `polling.ts`、`types.ts`、`test/polling.test.ts`。

**Interfaces:** `pollWanTask(options: PollWanOptions): Promise<WanPollResult>`。

```ts

  wait: boolean;
  timeoutMs: number;

  now?: () => number;
  sleep?: (ms: number) => Promise<void>;

// pollingContext 和可选 queryError；运行期校验外部上下文时间戳。
```

- [ ] 使用模拟时钟测试 `unknown → in_progress → completed`，确保到达成功、查询次数正确、仅查询没有 POST。
- [ ] 测试持续 unknown 满 120 秒停止并返回 queryError，isFailure=false；外部单次查询传回 pollingContext 后观察窗口不能重置。
- [ ] 测试 queued 超时保持 shouldPoll=true、timedOut=true；401 立即停止；429／5xx／网络失败最多连续重试 3 次且不超过总截止时间，成功查询后重置连续错误次数。
- [ ] 轮询算法使用注入 now／sleep，不将休眠或重试放进创建调用；单次模式只发一次 GET，返回可传给下次调用的上下文。未识别 schema 作为明确查询异常，不无限等待。

```ts
let clockMs = 0;
const responses = [
  { task_id: 'task_sample', status: 'unknown' },
  { task_id: 'task_sample', status: 'in_progress' },
  { task_id: 'task_sample', status: 'completed', metadata: { url: 'https://media.example.test/v.mp4' } },
];
const result = await pollWanTask({
  taskId: 'task_sample', wait: true, timeoutMs: 1_200_000,
  query: async () => responses.shift()!,
  now: () => clockMs,
  sleep: async (ms) => { clockMs += ms; },
});
assert.equal(result.isSuccess, true);
assert.equal(result.pollCount, 3);
assert.equal(result.timedOut, false);
assert.ok(clockMs <= 40_000);
```
