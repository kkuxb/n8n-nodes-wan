# Wan 视频生成 0.1.1

凭证新增服务商选择：默认「龙猫API」（`https://ai.lmao.net.cn`），可切换为「麦包API」（`https://ai.maibao.chat`）。仅切换根地址，沿用相同的 `wan3.0-video` 模型、接口后缀和请求参数。

已有麦包凭证保留原地址及工作流绑定；创建任务仍默认 1080P、等待完成并下载视频到 `binary.video`。支持文生视频、首帧／首尾帧、多模态参考、编辑和延长。

## 安装或升级

1. 下载本页附件 `n8n-nodes-wan-0.1.1.tgz`，可使用 `SHA256SUMS.txt` 校验文件。
2. 在 n8n 社区节点目录（通常为 `~/.n8n/nodes`）运行 `npm install /absolute/path/n8n-nodes-wan-0.1.1.tgz`。Docker 部署需使用容器内路径。
3. 重启 n8n，选择「Wan 视频生成」节点，并配置「Wan API」凭证。切换服务商时填写对应 Key，任务须在创建它的服务商处查询。

此版本通过 GitHub Release 分发，未发布 npm。附件 `.tgz` 已包含编译后的节点；GitHub 自动生成的 Source code 压缩包是源码，需要先安装开发依赖并构建。
